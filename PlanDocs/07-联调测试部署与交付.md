# 阶段 7：联调、测试、部署与交付

## 1. 阶段目标

完成全系统联调、质量检查、部署和毕业设计交付材料，确保项目可启动、可演示、可复现。

## 2. 联调顺序

1. 启动 MySQL 和 Redis，执行数据库表结构与演示数据脚本。
2. 启动后端，使用 Swagger 验证认证、分页、错误码和权限。
3. 启动前端，配置 API 基地址，先联调登录和路由守卫。
4. 按阶段顺序联调成员、活动、课程、作品、论坛和个人中心。
5. 最后联调管理端统计、日志、文件上传和异常场景。

## 3. 测试范围

### 3.1 功能测试

- 注册登录、退出、Token 失效和密码修改。
- 入社申请、成员审核和成员状态。
- 活动创建、发布、报名、取消报名、满员和截止时间。
- 课程发布、课时管理、视频播放和进度保存。
- 文件上传、作品审核、点赞、收藏、评论和下架。
- 帖子、公告、个人中心和积分流水。
- 用户、角色、统计、日志和系统配置。

### 3.2 接口测试

每个接口至少验证成功、缺少必填参数、未登录、无权限、资源不存在和重复提交。核心写接口使用事务和幂等测试，分页接口验证第一页、最后一页、空结果和非法页码。

### 3.3 前端测试

检查加载中、空数据、接口失败、上传失败、表单校验、按钮防重复提交、浏览器刷新、返回上一页和移动端布局。重点页面使用 Chrome 开发者工具检查控制台错误和网络请求。

### 3.4 安全与性能检查

- 密码、Token 和敏感用户信息不出现在日志中。
- 未授权接口不能通过修改 URL 或请求体绕过权限。
- 上传文件不能执行脚本，文件名不能造成路径穿越。
- 列表接口均分页，常用查询有索引。
- 对登录、报名、点赞和上传接口进行简单并发或重复请求验证。

## 4. 部署清单

### 4.1 配置

- 数据库连接、Redis 连接、JWT 密钥、文件目录和 CORS 白名单。
- 开发、测试、生产配置分离，敏感值通过环境变量提供。
- 前端生产构建时配置后端 API 地址。

### 4.2 部署步骤

1. 安装 Java 17、Node.js、MySQL 8、Redis 和 Nginx。
2. 创建数据库并执行 `schema.sql`、`data.sql`。
3. 构建后端 JAR，配置运行参数并启动 Spring Boot。
4. 执行前端 `npm install` 和 `npm run build`，将 `dist` 部署到 Nginx。
5. 配置 Nginx 静态资源、API 反向代理和前端 history 路由回退。
6. 使用测试账号验证登录、用户端、管理端和文件访问。

## 6. 最终验收

- 新环境按照部署说明可以完成启动。
- 普通用户、管理员、超级管理员三条主流程全部可演示。
- 核心业务数据可新增、查询、修改、审核和删除，状态流转正确。
- 前后端无关键控制台错误，接口异常有统一提示。
- 文档中的接口、字段、页面和实际实现保持一致。
